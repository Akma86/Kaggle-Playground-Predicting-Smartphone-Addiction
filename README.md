# Kaggle Playground Series - Season 6, Episode 8

This repository contains my solution and code for the Kaggle Playground Series: Season 6, Episode 8.

## Folder Structure
- `data/raw/`: Original dataset (train, test, sample_submission).
- `data/processed/`: Processed data features and engineered datasets.
- `notebooks/`: Jupyter notebooks for EDA, prototyping, and analysis.
- `src/`: Source code for the project.
  - `features/`: Scripts to turn raw data into features.
  - `models/`: Scripts to train models and make predictions.
  - `utils/`: Helper functions.
- `models/`: Saved model weights and artifacts.
- `submissions/`: CSV files ready for Kaggle submission.
