## 📖 Overview
Welcome to my solution repository for the **[Kaggle Playground Series S6E8](https://www.kaggle.com/competitions/playground-series-s6e8)**! This competition focuses on building robust machine learning models to predict smartphone addiction based on various behavioral and demographic metrics.

## 📂 Project Structure
A structured and modular approach for data science experiments:

```text
├── data/
│   ├── raw/               <- Original Kaggle dataset (ignored in Git)
│   └── processed/         <- Cleaned data and engineered features
├── notebooks/             <- Jupyter notebooks for EDA and prototyping
├── src/                   <- Source code for use in this project
│   ├── features/          <- Scripts for feature engineering
│   ├── models/            <- Scripts to train models and make predictions
│   └── utils/             <- Helper functions (metrics, logging, etc.)
├── models/                <- Trained models and artifacts (e.g. .pkl, .pt)
├── submissions/           <- Output CSV files ready for submission
└── README.md              <- Top-level README for developers
```

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Akma86/Kaggle-Playground-Predicting-Smartphone-Addiction.git
cd Kaggle-Playground-Predicting-Smartphone-Addiction
```

### 2. Setup the Environment
It is recommended to use a virtual environment:
```bash
python -m venv venv
# On Windows use:
venv\Scripts\activate
# Install requirements (if any)
# pip install -r requirements.txt
```

### 3. Download the Data
Place the competition data (`train.csv`, `test.csv`, `sample_submission.csv`) inside the `data/raw/` directory.
